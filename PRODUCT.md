# Product

## Register

Public profile for an independent evaluator and toolmaker. Feature-first,
calm, evidence-bound.

## Users

GitHub visitors, prospective clients, evaluators, funders, collaborators and
hiring teams who need a fast, honest map of Zain Dana Harper's work.

## Purpose

The `HarperZ9` profile README is the GitHub door into the work. Since
2026-10-01 it covers the current scope in this order:

1. Flywheel and the flagships: what the tools do, the commands to run, the
   honest null, and the current release of each flagship.
2. Who Knew First and the series: the finding, the published pieces, the
   planned pieces marked as planned, and the model-use disclosure.
3. The direction: trace observation and a check before each consequential
   action, with what exists today and the stated exclusion of hidden
   reasoning extraction.
4. Work with me: scoped consulting, the independence rules and the public
   income ledger commitment, plus roles and paths in a collapsed section.
5. Reach me: published routes only.

Depth lives in collapsed `<details>` sections so the first screen stays short.
The retro, graphics and security catalogs live on the site, which the profile
links to.

## Brand personality

Precision instrument, reserved energy. Artistic in the generated plates,
plain in the words. Human and fallible, never hyped.

## Art and interaction

- Every image is generated by `scripts/profile_art.py` from the design canon:
  the aperture form, fine radial line-work, halftone, scanlines, grain and crop
  marks, on the void and bone grounds. The spectrum appears only as the one
  flare on an aperture rim.
- Each plate has light and dark variants served through `<picture>` with
  `prefers-color-scheme`. Plates link to the live page they illustrate.
- Motion is slow CSS animation inside the SVG. CSS was chosen over SMIL because
  SMIL ignores `prefers-reduced-motion`; with CSS, reduced motion stops every
  animation.
- Interaction stays GitHub-native: a pick-a-door table of in-page links,
  collapsed sections, a Mermaid diagram, and badges that open live releases.
- `scripts/refresh_profile.py`, run daily by `.github/workflows/refresh.yml`,
  rewrites the release table, the latest-writing list and the version badges
  from the GitHub releases API and the site feed. It uses only `GITHUB_TOKEN`.

## Anti-references

Visitor counters, typing SVGs, generic stats cards, third-party badge
services, pills, gradient text, and any claim without a live link.

## Claim rules

- Flywheel is described capability first: workstation, any-model gateway,
  Rowan, Relay, lanes, `check-output`, receipts, local data. The honest null is
  one bounded caveat.
- Source-available, never open source. Real commands only.
- No client, partnership or lab-engagement claims. "No paid client today and
  no current sponsors" stays until the income ledger says otherwise.
- No hourly figures or discounts. Quotes are scoped.
- Planned work is marked planned and carries no link.
- No hashes, seeds, slugs or receipt counts on the reader surface.

## Accessibility

Every image has alt text that states its point, or empty alt when it is a
divider. All key claims exist as real text. Contrast follows the site tokens.
Animation respects `prefers-reduced-motion`.
